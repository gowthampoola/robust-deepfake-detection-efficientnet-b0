# Evaluation Results & Demonstrations

This directory stores evaluation summaries, prediction logs, confusion matrix figures, and visual demonstration previews generated by the evaluation scripts.

- `demo_processed_gaussian_blur_r2.jpg`: Sample visual artifact generated by `evaluation/demo_compare_postprocessing.py` showing image degraded by Gaussian blur ($r = 2.0$).
- Additional demonstration outputs generated when executing `evaluation/demo_compare_postprocessing.py` across different post-processing choices will be saved here automatically.
